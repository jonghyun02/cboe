# CBoE — 근거를 제시하는 SDH 자막 검수 보조 도구

## 단계 (덱 5.1)

| 단계 | 덱 | 하는 일 | 모델 |
|---|---|---|---|
| ingest | 영상 | 처리 구간 소리 뽑기 | ffmpeg |
| script | 대본 | 촬영 대본을 장면·지문·대사로 읽기 | 규칙 |
| separate | 5.2 음원 분리 | 대사·음악·효과음 3트랙 | Bandit v2 다국어판 |
| cuts | 5.5 장면 나누기 | 장면 전환 | TransNetV2 |
| sed | 5.3·5.4 | 효과음·원본·음악 트랙 447종 점수(40ms), 트랙 소리 세기 | PretrainedSED (BEATs) |
| asr | 5.2 대사 트랙 | 받아쓰기 낱말 시각 | Whisper large-v3 (faster-whisper; 인텔 GPU는 OpenVINO) |
| align | 5.2 대사 트랙 | 장면 자리를 먼저 찾고 대본 줄을 맞춤, 줄 상태, 대본과 들린 말 대조 | 규칙 |
| cues | 대본 | 지문의 소리·음악·침묵을 단서로, 단서마다 시간 창 | 규칙 |
| sfx | 5.3 효과음 검출 | 소리 첫 프레임, 확실한 만큼 구체적인 종류(AudioSet 계층), 목록 밖 소리 | 규칙 + 계층 |
| music | 5.4 음악 검출 | 음악 시작·새 음악·분위기 바뀜·갑자기 멈춤, 분위기 7종 비율, 악기 | PretrainedSED 'Music', AST |
| speaker | 5.6 화자 근거 | 줄마다 말하는 얼굴이 보이나 | YuNet + LR-ASD |
| screen | 5.5 화면 근거 | 소리 낸 출처·동작이 보이나, 인물 반응 | Claude (프레임 3장) |
| dialog_ev | 대사 근거 | 앞뒤 대사의 반응·언급, 대사에 이미 적힌 소리 | Claude (글) |
| recommend | 5.7 추천 | 대본 단서를 후보에 붙임 → 이미 전해지나 → 넣을 근거 있나 → 에이전트 | 규칙 |
| agent | 5.8 재확인 | 애매한 후보만 도구(재검출·소리 설명·프레임·대사 검색)로 다시 확인 | Claude + MCP 도구, Qwen2.5-Omni-3B |
| (placement) | 5.9 초안 배치 | 자리·시간·가독성(16자·2줄·초당 14자·5/6~7초·2프레임) | 규칙 |
| server | 5.10, 3.x 검수 화면 | 근거 보고 확정(후보·대사 줄·인물 표시), 고칠 때마다 배치 다시, SRT·VTT·TTML | FastAPI |
| check | 내보낸 자막 검사 | 내보낸 파일을 지침 조항대로 다시 검사 | 규칙 |

자세한 사용법은 `USAGE.md`, 설계와 파일 형식은 `DESIGN.md`.
